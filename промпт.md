## 1. Схема базы данных (server/db/schema.sql)

### Новая таблица: educational_institutions
Создай таблицу учебных заведений, привязанных к профессии:

CREATE TABLE IF NOT EXISTS educational_institutions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,             -- название заведения
  type TEXT NOT NULL,             -- 'вуз' | 'колледж' | 'техникум'
  website TEXT,                   -- ссылка на сайт (опционально)
  created_at TEXT DEFAULT (datetime('now'))
);

### Новая таблица: profession_educational_institutions (many-to-many)

CREATE TABLE IF NOT EXISTS profession_educational_institutions (
  profession_id INTEGER NOT NULL REFERENCES professions(id) ON DELETE CASCADE,
  institution_id INTEGER NOT NULL REFERENCES educational_institutions(id) ON DELETE CASCADE,
  PRIMARY KEY (profession_id, institution_id)
);

### Новая таблица: vacancy_applications (отклики на вакансии)

CREATE TABLE IF NOT EXISTS vacancy_applications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  enterprise_id INTEGER NOT NULL REFERENCES enterprises(id) ON DELETE CASCADE,
  profession_id INTEGER NOT NULL REFERENCES professions(id) ON DELETE CASCADE,
  created_at TEXT DEFAULT (datetime('now')),
  UNIQUE(user_id, enterprise_id, profession_id)  -- защита от дублей
);

### Новая таблица: vacancies (вакансии предприятия)

CREATE TABLE IF NOT EXISTS vacancies (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  enterprise_id INTEGER NOT NULL REFERENCES enterprises(id) ON DELETE CASCADE,
  profession_id INTEGER NOT NULL REFERENCES professions(id) ON DELETE CASCADE,
  available_slots INTEGER NOT NULL DEFAULT 1,  -- кол-во вакантных мест
  created_at TEXT DEFAULT (datetime('now')
);

Добавь в server/db/seed.js тестовые данные для новых таблиц (2–3 учебных заведения, 2–3 вакансии).

### 2.4. Новый контроллер: server/controllers/vacanciesController.js

Функция getEnterpriseVacancies:
- SELECT vacancies.id, professions.title AS profession_title, vacancies.available_slots
  FROM vacancies
  JOIN professions ON vacancies.profession_id = professions.id
  WHERE vacancies.enterprise_id = req.params.id
- Возвращает массив { id, profession_title, available_slots }

Функция applyToVacancy:
- Middleware: requireAuth (JWT)
- Проверить существование вакансии по req.params.id
- INSERT OR IGNORE INTO vacancy_applications (user_id, enterprise_id, profession_id)
- При дубле (UNIQUE constraint) — вернуть 409 { error: 'Вы уже откликались на эту вакансию' }
- При успехе — вызвать sendVkNotification(applicationData) (см. п. 2.5)
- Вернуть 201 { success: true, message: 'Отклик отправлен' }

### 2.5. Утилита: server/utils/vkNotify.js

Создай функцию sendVkNotification({ userName, enterpriseName, professionTitle, createdAt }):
- Использует VK API метод messages.send (или wall.post) для отправки сообщения администратору сайта от имени сообщества.
- VK_ADMIN_ID и VK_TOKEN берутся из переменных окружения (process.env)
- Формат сообщения:
  «📩 Новый отклик на вакансию!
  👤 ФИО: {userName}
  🏭 Предприятие: {enterpriseName}
  💼 Профессия: {professionTitle}
  🕒 Дата: {createdAt}»
- Ошибки отправки логировать через Winston (logger.warn), не бросать исключение (не блокировать основной ответ)
